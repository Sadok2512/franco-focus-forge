CAUSE
Frontend proxy logs at 2026-10-18 20:54:34 show failed map/distribution requests for multiple parameters, followed by ECONNREFUSED. Docker records the API container start at 20:54:34.901 UTC, matching the interruption. Another API restart at 20:57:06 interrupted the first verification login. The backend was not restarted or changed for this correction.
The exact 2- and 3-parameter combinations from the proxy error log were retried through the frontend proxy after service recovery: all four requests returned HTTP 200 (distribution 300/305 ms; map 60/38 ms). No multi-selection API defect was reproduced on the available backend.

CORRECTION
Map/distribution requests retry only network and HTTP 502/503/504 errors, at most five retries, with backoff 2/4/8/10/10 seconds. Validation, authentication, schema, cancellation and server-logic errors are not automatically retried. Selections, applied filters and existing data remain intact. Reconnection status is explicit; exhausted failures retain a manual Retry action, now also available for histogram/table results.
